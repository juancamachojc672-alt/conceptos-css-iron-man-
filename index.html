          MÓDULO 2.1
          
Estructura y sintaxis

          
Una regla CSS responde tres preguntas: a quién se aplica (selector), qué cambia (propiedad) y cómo cambia (valor). Pasa el cursor por el código para ver cada pieza.

        


        

          

            
Anatomía de una regla

            
/* esto es un comentario */
.panel {
  color: gold;
  padding: 1rem 2rem;
}

            

              Pasa el cursor por el código
              Cada color es una parte distinta de la sintaxis.
            

            
Una declaración es la pareja propiedad: valor;. Un bloque puede tener todas las que necesite.

          MÓDULO 2.2
          
Tipos de incorporación

          
Hay tres formas de conectar CSS con HTML: interno, externo y en línea. Elige una pestaña para ver el código y cuándo conviene.

        


        

          

            
            
            
          


          

            

              

                
<head>
  <style>
    .boton {
      background: #e4262c;
      color: white;
    }
  </style>
</head>

                
    
                  
  • Todo en un solo archivo: práctico para pruebas rápidas.
    • 
                  
  • Va dentro de <style>, normalmente en el <head>.
    • 
                  
  • No se reutiliza en otras páginas.
    • 
                

              

              

                
<head>
  <link rel="stylesheet" href="styles.css">
</head>

/* styles.css */
.boton {
  background: #e4262c;
  color: white;
}

                
    
                  
  • Un archivo .css sirve para muchas páginas.
    • 
                  
  • El navegador lo guarda en caché y carga más rápido.
    • 
                  
  • Es la forma recomendada en proyectos reales.
    • 
                

              

              

                
<button class="boton"
  style="background:#e4262c; color:white;">
  Activar
</button>

                
    
                  
  • Se aplica a un solo elemento, sin selector.
    • 
                  
  • Mezcla contenido con estilo y es difícil de mantener.
    • 
                  
  • Tiene mucha especificidad: cuesta sobrescribirlo.
    • 
                

              

            


            

              

                Estilo cargado desde
                <style> interno
              

              
Si dos reglas tienen el mismo peso, gana la que aparece más abajo en el código. Por eso el orden de los <link> importa.

            

          

        

      

    


    
    

      
2.3

      

        

          MÓDULO 2.3
          
Identación, herencia y comentarios

          
Tres hábitos que separan un código que se lee bien de uno que nadie quiere tocar.

        


        

          
Identación: el mismo código, dos estilos

          

            

              ✗ sin orden
              
.panel{color:gold;padding:1rem;
border:1px solid red}
.panel a{color:white;
text-decoration:none}

            

            

              ✓ con identación
              
.panel {
  color: gold;
  padding: 1rem;
  border: 1px solid red;
}

.panel a {
  color: white;
  text-decoration: none;
}

            

          

          
Una propiedad por línea, dos espacios por nivel y una línea en blanco entre reglas. Los errores saltan a la vista.

        


        

          

            
Herencia

            
Algunas propiedades pasan de padre a hijo solas; otras no. Cambia el padre y observa.

            

              .padre
              

                .hijo
                
.nieto

              

            

            

              
              
              
            

            
            
            
    
            
    
          
    

          
    
            
    Comentarios
    
            
    Los comentarios /* … */ no se ejecutan. Sirven para explicar o para apagar una línea sin borrarla. Haz clic en una línea.
    
            
    
            
    
              
      background: #e4262c;
    
              
      box-shadow: 0 0 34px #e4262c;
    
              
      border-radius: 50%;
    
              
      transform: rotate(45deg);
    
            
    
            
    Atajo en editores: Ctrl + / comenta o descomenta la línea.

          MÓDULO 2.4
          
    Niveles de especificidad
    
          
    Cuando dos reglas apuntan al mismo elemento, el navegador compara su peso. Se cuenta en cuatro columnas y se comparan de izquierda a derecha.
    
        
    

        
    
          
    La escalera de peso
    
          
    
            
    1 · 0 · 0 · 0Estilo en línea style="…"
    
            
    0 · 1 · 0 · 0Id #menu
    
            
    0 · 0 · 1 · 0Clase, atributo, pseudo-clase .item [href] :hover
    
            
    0 · 0 · 0 · 1Etiqueta y pseudo-elemento p ::before
    
          
    
          
    !important salta toda la escalera, por eso es mejor no abusar de él. Un * no suma nada.
    
        
    

        
    
          
    
            
    Calculadora
    
            
            
    
              
              
              
              
            
    
            
    
              
    0en línea
    
              
    0ids
    
              
    0clases
    
              
    0etiquetas
    
            
    
            
    
          
    

          
    
            
    Batalla de reglas
    
            
    Activa varias reglas sobre el mismo texto, cada una con su propio color. Gana la de más peso.
    
            
    Texto objetivo
    
            
    
            
    
            
    En esta demo usamos un elemento propio para no afectar al resto de la página; las reglas funcionan igual que con p.

    2.6
    
      
    
        
    
          MÓDULO 2.6
          
    Media queries
    
          
    Una media query es un if de CSS: las reglas de dentro solo se aplican si la condición se cumple. Cambia el tamaño de la ventana y mira el radar.
    
        
    

        
    
          
    
            
    Sintaxis
    
            
    /* móvil primero */
.menu { display: none; }

@media (min-width: 768px) {
  .menu { display: flex; }
}

/* combinando condiciones */
@media (min-width: 601px) and (max-width: 1024px) {
  .tarjeta { width: 50%; }
}

/* preferencias del usuario */
@media (prefers-color-scheme: dark) {
  body { background: #000; }
}
    
            
    Mobile first usa min-width y va sumando reglas; desktop first usa max-width y las va quitando.
    
          
    

          
    
            
    Radar de condiciones
    
            
    0 × 0 px
    
            
      
            
      
          
      
        
      
      
      
    
      

    
    
      
      
      2.7
      
      
      
        
      
          MÓDULO 2.7
          
      Pseudo-elementos
      
          
      Con doble dos puntos :: estilizas una parte de un elemento, o creas contenido decorativo sin tocar el HTML.
      
        
      

        
      
          
      
            
      ::before y ::after
      
            
      SISTEMA
      
            
      .estado::before { content: "● "; }
.estado::after  { content: " // OK"; }
      
          
      

          
      
            
      ::first-letter
      
            
      La primera letra de este párrafo se agranda como en una revista antigua.
      
            
      p::first-letter {
  font-size: 3rem;
  float: left;
  color: red;
}
      
          
      

          
      
            
      ::first-line
      
            
      Solo la primera línea cambia de estilo; si cambias el ancho de la ventana, el cambio se adapta al texto que quepa en ella.
      
            
      p::first-line {
  color: gold;
  text-transform: uppercase;
}
      
          
      

          
      
            
      ::selection
      
            
      Selecciona este texto con el mouse para ver el nuevo color de selección.
      
            
      p::selection {
  background: red;
  color: white;
}
      
          
      

          
      
            
      ::placeholder
      
            
      
            
      input::placeholder {
  color: gold;
  letter-spacing: .2em;
}
      
          
      

          
      
            
      ::marker
      
            
      • Reactor
      • Escudo
      • Radar
      
            
      li::marker {
  content: "▸ ";
  color: red;
}
      
          
      
        
      

        
      
          
      Truco con ::after: un barrido de luz
      
          
      Pasa el cursor por aquí
      
          
      .boton { position: relative; overflow: hidden; }
.boton::after {
  content: "";
  position: absolute;
  left: -60%;
  transition: left .8s;
}
.boton:hover::after { left: 130%; }
      
        
      
      
      
    
      

    
    
      
      
      2.8
      
      
      
        
      
          MÓDULO 2.8
          
      Pseudo-clases
      
          
      Con un solo : eliges un elemento según su estado (si lo tocas, si está marcado) o su posición (el tercero, el último).
      
        
      

        
      
          
      
            
      :hover · :active · :focus-visible
      
            
      
            
      .btn:hover   { background: gold; }
.btn:active  { transform: scale(.94); }
.btn:focus-visible { outline: 2px solid cyan; }
      
            
      Prueba también con la tecla Tab.
      
          
      

          
      
            
      :focus-within
      
            
      
              
      
                
                
              
      
            
      
            
      .campo:focus-within {
  border-color: gold;
}
.campo:focus-within label { color: gold; }
      
          
      

          
      
            
      :checked
      
            
      
              
      
                
                
                
              
      
            
      
            
      .sw:checked + .pista {
  background: red;
}
.sw:checked ~ .texto::after {
  content: "ACTIVADO";
}
      
          
      

          
      
            
      :valid · :invalid
      
            
      
              
      
                
                
              
      
            
      
            
      input:valid   { border-color: lime; }
input:invalid { border-color: red; }

          MÓDULO 2.9
          
      Z-index
      
          
      z-index decide quién queda encima cuando los elementos se superponen. Solo funciona en elementos con position distinto de static, y dentro de su propio contexto de apilamiento.
      
        
      

        
      
          
      
            
      
              
      Az-index: 1
      
              
      Cz-index: 2
      
              
      
                
      Bz-index: 99
